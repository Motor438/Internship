# Summer 2027 Internship Board

A dashboard for tracking Summer 2027 operations, HR and marketing internships.

- `index.html` – the whole site (HTML, CSS and JavaScript in one file)
- `internships.json` – the role list. New roles are added here each morning.

Statuses and notes are saved in your browser (localStorage). Use **Back up progress** in the footer to move them to another device.
